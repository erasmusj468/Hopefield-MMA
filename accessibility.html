HOPEFIELD MMA • WEBSITE INFORMATION

ACCESSIBILITY.

Hopefield MMA's approach to accessible website content and navigation.

Last updated: 24 November 2026

Hopefield MMA aims to make its website usable by as many people as possible, including visitors using keyboards, screen readers, magnification and mobile devices. Accessibility is ongoing; this statement is not a claim that every page has passed a formal accessibility audit.

1. Current accessibility features

  • Semantic page landmarks and labelled navigation.
  • Text alternatives for meaningful team, achievement and gallery images.
  • Labels for contact-form fields and a privacy acknowledgement.
  • Visible keyboard focus indicators and keyboard controls for the image viewer.
  • Reduced-motion preferences for selected interface effects.
  • Responsive layouts for mobile and desktop screens.

2. Known limitations

Some older photographs or small decorative elements may not have ideal text alternatives or contrast in every context. The club will review reported barriers and improve the website where reasonably possible.

3. Report a problem

If you have difficulty using a page, reading text, completing the enquiry form or navigating with a keyboard or assistive technology, contact erasmusj468@gmail.com or call 082 867 2395. Please mention the page and what made it difficult, if possible.
